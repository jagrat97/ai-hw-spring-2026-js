Assignment #7.1 — gradient-based adversarial examples vs a CNN

Jagrat Shrivastav · AI HW, Spring 2026

The Idea

  • A CNN classifies MNIST digits at 98.99% accuracy.
  • Add a tiny, human-invisible perturbation to the pixels …
  • … and the same model confidently predicts the wrong digit.
  • Threat model: untargeted, L∞-bounded (each pixel moves ≤ ε), inputs kept in [0,1].

Three Attacks

FGSM — one gradient step (Goodfellow 2014):

x_adv = x + ε · sign(∇x L)

I-FGSM / PGD — 10 small steps, projected back into the ε-ball:

xt+1 = clipε( xt + α · sign(∇x L) )

MI-FGSM — I-FGSM with momentum (Dong 2018, μ=1.0):

gt+1 = μ·gt + ∇L / ‖∇L‖1  ;  xt+1 = clipε( xt + α·sign(gt+1) )

Clean Baseline

98.99%

recognition accuracy on the 10,000-image MNIST test set, before any attack.

Attack success rate (ASR) = fraction of originally-correct images flipped to a wrong label.

Attack Success vs ε

ASR rises monotonically with the perturbation budget. Iterative attacks dominate single-step FGSM.

Takeaways

  • A 98.99%-accurate CNN is not robust — tiny L∞ noise breaks it.
  • ASR grows with ε; iterative attacks (I-FGSM, MI-FGSM) beat single-step FGSM.
  • At ε=0.3 the model is essentially destroyed (>99% ASR).
  • MI-FGSM matches I-FGSM here; its real edge is transferability across models.
  • Reproducible: python train.py then python test.py.
